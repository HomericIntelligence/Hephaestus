# ASD-STE100 Writing Standard

## Policy

Hephaestus uses ASD-STE100 Simplified Technical English as its writing
standard. Hephaestus adopts Issue 9, dated January 15, 2025. The project will
use this issue until it explicitly adopts a later issue.

This requirement is a Hephaestus policy. It does not state or imply that ASD
or the ASD Simplified Technical English Maintenance Group (STEMG) approves,
certifies, or endorses Hephaestus.

## Scope

Use the standard for all English technical prose that Hephaestus creates or
revises. This scope includes:

- Hephaestus-owned skill text, agent instructions, and packaged prompt
  templates;
- text that an agent creates when it uses an external skill;
- technical documentation, code comments, and docstrings;
- user-interface and command-line text; and
- issue and pull-request text.

This policy has priority over other writing-style directions in a Hephaestus
prompt or in external skill text that Hephaestus supplies to an agent.

The formal scope of ASD-STE100 is technical documentation. The larger scope in
this policy is a Hephaestus house-style decision. Do not describe the larger
scope as the formal scope of ASD-STE100.

Hephaestus does not own the source text of the Athena skills that it uses. Do
not change third-party skill source text or versioned external contract
fixtures. Apply this policy to new or revised output when Hephaestus supplies
external skill text to an agent.
When an agent creates a prompt for another agent, it must include the complete
writing standard directive in the new prompt.

Required literals are not prose. Preserve code, commands, identifiers, schema
keys, machine-readable formats, quotations, and text that an external source
controls.

## Principles exception

Do not change the wording of project principles only to satisfy ASD-STE100.
This exception applies only to sections or prompt blocks that explicitly
declare project principles, including specialized principle lists. References
to, explanations of, and applications of a principle must follow the writing
standard.

## Official source

Use the official ASD-STE100 document as the primary reference. The STEMG
provides information on the
[official ASD-STE100 website](https://www.asd-ste100.org/). You can
[request a free official copy](https://www.asd-ste100.org/STE_downloads.html).

Do not add the standard, its rules, its dictionary, its PDF, or the ASD logo to
this repository. A writing tool can help an author, but it cannot replace the
official standard or informed review.

ASD-STE100 Simplified Technical English is a registered trademark of ASD. Use
the name only to identify the standard. Do not use it as Hephaestus branding.
