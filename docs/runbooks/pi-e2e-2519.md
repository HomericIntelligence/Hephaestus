# Pi Issue 2519 Runbook

This runbook collects closure evidence for [issue #2519](https://github.com/HomericIntelligence/Hephaestus/issues/2519) without reimplementing the queue pipeline.

- Evidence status: `incomplete`
- Private evidence lives under `build/pi-e2e-2519/<run-id>/`.
- Pi is observed only through the normal planner and automation-loop entry points.
- Athena `advise` and `learn` remain host-owned; the queue emits their typed receipts.

## Collection

1. Install and select a reviewed external Pi isolation adapter with `HEPH_PI_ISOLATION_ADAPTER`.
2. Initialize the private run and record inventory plus a repository snapshot.
3. Capture the normal planning command with `--agent pi`.
4. Capture the normal implementation/review/handoff loop with `--agent pi`.
5. Retain the typed Athena and provider receipts emitted by those queue runs.
6. Run the same fixture through a Codex control where practical.
7. Record every defect as an open follow-up issue with a literal `Parent: #2519` line.
8. Snapshot the final publication commit, then render, verify, and attest that exact live PR head.

Direct Pi commands are rejected because they cannot prove the queue path.

## Commands

```bash
uv run python scripts/pi_e2e_2519.py init --run-id <run-id>
uv run python scripts/pi_e2e_2519.py inventory --run-id <run-id>
uv run python scripts/pi_e2e_2519.py snapshot --run-id <run-id> --label repo-snapshot

uv run python scripts/pi_e2e_2519.py capture --run-id <run-id> \
  --stage discovery-plan --provider pi -- \
  uv run hephaestus-plan-issues --issues 2519 --parallel 1 --agent pi --json

uv run python scripts/pi_e2e_2519.py capture --run-id <run-id> \
  --stage implementation-review-handoff --provider pi -- \
  uv run hephaestus-automation-loop --issues 2519 --agent pi --json

uv run python scripts/pi_e2e_2519.py record-defect --run-id <run-id> \
  --summary "<summary>" --follow-up-issue <issue-number>
uv run python scripts/pi_e2e_2519.py snapshot --run-id <run-id> \
  --label publication-snapshot
uv run python scripts/pi_e2e_2519.py render --run-id <run-id>
uv run python scripts/pi_e2e_2519.py verify --run-id <run-id> \
  --criterion completion --report docs/pi-e2e-2519-report.md \
  --runbook docs/runbooks/pi-e2e-2519.md
uv run python scripts/pi_e2e_2519.py attest-publication --run-id <run-id> \
  --repo HomericIntelligence/Hephaestus --ref <commit-sha> --pr <pr-number> \
  --verify-defects
```

## Evidence Rules

- `capture` enables the pipeline's private typed receipt sink and requires Pi session identifiers plus resolved tool scopes from those queue-worker receipts.
- Requested skill grants and provider text are not skill-invocation evidence.
- `mnemosyne` accepts only queue-emitted Athena receipts and revalidates them against the packaged contract, canonical checkout head, and live learning PR.
- Defect receipts are read twice from the scoped GitHub host and revalidated before publication.
- Publication is accepted only for an open exact-head PR with `Closes #2519`, `state:implementation-go`, no NOGO label, no unresolved threads, and no native auto-merge request.
